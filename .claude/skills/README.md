# Agent skills

The EmDash skills in this folder are copied from [emdash-cms/skills](https://github.com/emdash-cms/skills)
at commit `09e4e7602e0247e2c448811cca863c1c7a84b510` (MIT, see `EMDASH-SKILLS-LICENSE`).
Claude Code loads project skills from `.claude/skills/` automatically.

To update, replace these folders with the latest `skills/` directory from that repo,
or run `npx skills add emdash-cms/skills` locally.
